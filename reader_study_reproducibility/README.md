# Reader-study input framework

This directory provides synthetic input schemas and software environment records. It contains no actual reader identities, assignments, responses or clinical cases. The examples are artificial and do not reproduce study statistics.

Validate the examples with `python scripts/validate_synthetic_formats.py`. A framework integration should validate paired keys, response ranges, reference labels and agreement between input schemas before analyses. Study-specific statistical models and scientific outputs are not included in this pre-submission software tree. Preserve the complete study analysis package separately for reviewer access.
