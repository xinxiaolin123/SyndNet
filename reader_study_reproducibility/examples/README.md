# Reader input formats

These small artificial tables illustrate column names and pairing only. They contain no study readers, cases, responses or assignments and are not inputs for reproducing publication statistics. The study pipeline requires its approved complete controlled input bundle.

`paired_reader_format.csv` shows paired condition responses and the grouping fields required by crossed-effects analyses. `reader_assignment_format.csv` illustrates the separate controlled sequence lookup. `locked_prediction_format.csv` illustrates the locked model decision table. The pipeline derives condition-level records from approved paired records; it does not create or impute reader responses.
