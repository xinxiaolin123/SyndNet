# Frozen release and DOI archive

1. Complete the safety/integrity/numerical checks and publish the verified Git commit to the repository.
2. Create a GitHub release for the exact publication commit using tag `v1.0.0`. Attach the frozen repository archive and SHA256 manifest if desired.
3. Enable the repository in Zenodo's GitHub integration, then create the release after enabling it; alternatively deposit the exact release archive manually.
4. Review the actual Zenodo record, author metadata, Apache-2.0 software license, data rights and files before publishing it.
5. Replace DOI_PENDING with the actual version DOI in citation metadata and the manuscript. Record the version DOI and concept DOI distinctly.

No DOI, Zenodo record, or individual author information is fabricated. GitHub hosting alone does not establish archival permanence. Individual author names, ORCIDs, manuscript title and publication metadata must come from author-approved records before archival publication.

Official instructions: [Zenodo GitHub integration](https://help.zenodo.org/docs/github/enable-repository/); [Nature code-publication guidance](https://media.nature.com/full/nature-cms/documents/GuidelinesCodePublication.pdf).
