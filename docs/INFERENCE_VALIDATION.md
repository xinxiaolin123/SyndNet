# Runtime scope

The paired-image adapter was execution-tested in the recorded CUDA environment with strict checkpoint loading. Synthetic examples verify execution only; no diagnostic accuracy claim follows from them.

Probabilities depend on numerical precision and batch context. The adapter preserves its documented replicated-pair context. Arbitrary batching, CPU execution or changed libraries should not be assumed to reproduce the same probabilities. Original study evaluation requires its original execution context and is outside this public demonstration.
