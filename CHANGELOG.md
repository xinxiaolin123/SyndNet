# Changelog

## 1.1.1

Scientific documentation and citation metadata have been updated. The reader-study pipeline is organized under `reader_study_reproducibility/`, and lightweight numerical integrity checks are included. Frozen model tensors, residual scales, thresholds and publication numerical outputs are unchanged. Inference documentation describes the validated environment and batch-context sensitivity. Controlled-data access conditions and the software licence are documented.

## 1.1.0

Frozen inference checkpoints and a paired-image inference command were added with checkpoint hashes, strict loading and CUDA float16 fidelity verification.

## 1.0.0

Numerical reproduction code, derived predictions and reader-study analyses were released.
