# Code availability

Custom code, configuration files and frozen model checkpoints used to implement and evaluate SyndNet are publicly available through the [SyndNet GitHub repository](https://github.com/xinxiaolin123/SyndNet). The released checkpoints and locked inference pipeline enable reproduction of SyndNet inference on appropriately preprocessed paired anteroposterior and lateral ankle radiographs.

Full model retraining requires controlled-access radiographic data, annotations and study manifests. Source code is distributed under the Apache License 2.0. See [data access](DATA_ACCESS.md) for the controlled-data request mechanism.
