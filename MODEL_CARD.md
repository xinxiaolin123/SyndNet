# SyndNet software scope

SyndNet is an anatomy-informed deep learning framework for research with paired AP/lateral ankle radiographs. The software returns model probabilities and decisions using supplied checkpoint configuration.

This software document does not report study performance, cohort composition or architectural novelty. Clinical validity cannot be inferred from synthetic demonstrations. Alternative projections, postoperative imaging and other populations require independent validation. Outputs do not replace clinical or mechanical assessment.

Use the documented preprocessing and CUDA environment. CPU fidelity and changes to execution context are not established as equivalent. Data access is described in [DATA_ACCESS.md](DATA_ACCESS.md).
